# MLBot
Developed an automated web scraping bot designed to efficiently extract, parse, and structure offer data from Mercado Libre. The main goal of this project was to automate the tedious process of manual searching by gathering real-time listings into an organized format sended via telegram.

Desarrollo de un bot que hace web scraping diseñado para que eficientemente extraiga, lea y estructure ofertas de Mercado Libre. La meta principal del proyecto es automatizar el tedioso proceso manual de buscar ofertas en esta plataforma, las cuales se envian via telegram

Key Features & Functionality:

Automated Data Extraction: Developed python scripts using standard web parsing libraries to target specific HTML structures and extract relevant information (titles, links, and descriptions).

Data Cleansing: Implemented data filtering logic to ensure duplicates were removed and only clean, relevant URLs and details were preserved.

Autonomous Execution: Designed to handle standard web structures efficiently, laying the groundwork for scheduled automation tasks.

Technical Stack:

Language: Python

Core Concepts: HTML parsing, DOM traversal, and automation workflows.
